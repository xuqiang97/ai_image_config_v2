# AI 生图管理员配置二期

本期解决人员调岗后的生图凭据与费用归属问题，并支持按当前部门批量更新已有用户配置的 quota。

## 评审材料

- [HTML 交互原型](index.html)：沿用一期布局和蓝色主题，演示部门筛选、个人配置及部门批量额度更新。
- [产品需求文档 PRD](docs/v2/AI生图管理员配置二期-PRD.md)：业务规则、页面行为、权限边界及验收标准。

评审时先操作原型，再对照 PRD。生图配置的 `userId` 对应 `rb_admin.ID`，当前部门取 `rb_admin.DepartmentID`；新任务实际发起时实时查询，已提交任务沿用首次提交时的部门与凭据快照。组织归属更新由现有组织系统负责。具体接口、存储与任务实现交给研发。

## 本地查看

直接用浏览器打开本目录的 `index.html`，无需安装依赖。页面使用虚构数据，不连接真实接口；所有改动仅在当前页面生效，刷新恢复。

建议按以下顺序体验：

1. 在运营页面选择“销售部”，查询后勾选“包含下级部门”再次查询，对比范围。
2. 打开“按部门批量更新 quota”，选择“运营一组 + LinkFox”，查看命中数量与停用配置说明，再确认整份额度覆盖。
3. 使用“业务支持部 + LinkFox”查看无命中反馈；在新增中输入示例员工 `9199` 查看只读部门与配置流程。
4. 切换美工页面，核对其数据范围与运营页面独立。
5. 在运营页面新增示例用户 `9106` 的“自研”配置，查看“未匹配部门”仍可正常保存；展开页面顶部的“原型评审说明”查看新旧任务及异常处理规则。

部门缺失或未配置生图凭据时允许先保存人员额度配置；实际生图时若无法获取有效部门或凭据，任务判失败、记录原因并进入「已完成」。原型只演示配置页面的保存和反馈，实际生图、费用、实时组织查询及凭据快照规则由研发实现后验收。

## 当前状态

交付版本：PRD V1.2（2026-10-22）及配套轻量 HTML 原型，用于产品与研发评审。人员部门关联、实时查询、历史任务快照及异常处理均按最终规则说明。

仓库仅收录经审查的评审文档、虚构数据原型及必要配置。原始资料、真实部门数据、运行记录和本地截图不纳入版本管理。

一期项目只作为布局和既有规则参考，保持原文件不变。二期以本项目 PRD 和 HTML 为评审材料；两份源稿保持不变。[历史交接与核查](docs/v2/AI生图管理员配置二期-Codex交接与核查.md)仅供备查，其中较细的实现建议不再作为本轮产品方案的技术约束。
